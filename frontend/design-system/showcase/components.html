Color

Semantic tokens over a cool "ink" neutral ramp and the "signal" accent. Signal marks where you are and what you can do; it is never a status. Switch the theme to see every token remapped.

Status and severity

Status describes an operation or an object; severity describes a security finding or event. Severity always pairs color with a shape and a word, so it survives color blindness and forced colors.

Dangerous action ladder

Every state-changing action has one level, defined once in the action catalog. The open dialogs in the control plane example show levels 2 and 3 working.

LevelFrictionExamples
0 · ReversibleApplies at once; Undo for 10 secondsRename a group, add a member
1 · ConfirmDialog naming the object and the effectSuspend a user, disable an application
2 · Type to confirmType the object's nameDelete an application, revoke all sessions
3 · Recent authenticationInline step-up, passkey preferredRotate keys, grant an administrator role, publish to production
4 · Second approverA different administrator approvesGrant a platform role, disable audit delivery
Pointer or Space held for 1.5 seconds. Reserved for the most destructive actions.
